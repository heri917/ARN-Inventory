# ARN Inventory

**Stok & Part**

Starter PWA untuk ARN Inventory.

## Stack
React + Vite + Supabase

## Jalankan
```bash
npm install
npm run dev
```

Salin `.env.example` menjadi `.env.local`, lalu isi URL Supabase dan publishable/anon key.

## UI yang sudah disiapkan
- Header aman dari status bar
- ☰ menu
- Stok / History / Ringkasan
- Loading minimum 7 detik
- Animasi box 3D bergulir
- PWA manifest
- Struktur koneksi Supabase
- Mobile-first black/gold ARN
