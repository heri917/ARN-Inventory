# ARN Inventory - Current Build Specification

This build applies the locked ARN Inventory baseline: three primary pages (Stok, History, Ringkasan), hamburger drawer, mobile safe-area header, 7-second minimum splash, rolling box loading animation, official header/loading/developer assets, PWA manifest, relative GitHub Pages paths, and flat repository structure.

The broader product specification includes multi-account auth, licensing, Supabase stock/history architecture, master compatibility data, CSV backup/export, case-insensitive search, and the transaction rules previously agreed for the project. This starter is the deployment/UI foundation; those backend workflows must be implemented before claiming the product is feature-complete.
